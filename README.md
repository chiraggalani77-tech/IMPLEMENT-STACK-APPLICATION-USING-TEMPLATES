Stack Implementation

A data structure project implementing a Stack from scratch to understand the LIFO (Last In, First Out) principle and core stack operations.

Features

Push element

Pop element

Peek/Top element

Display stack

Check for overflow

Check for underflow

Empty stack detection

Array-based implementation

Dynamic memory implementation


Technologies

C / C++

Arrays

Pointers

Dynamic Memory Allocation

Functions

Data Structures


Core Operations

Operation	Description

push()	Adds an element to the top
pop()	Removes the top element
peek()	Returns the top element
display()	Displays all stack elements
isEmpty()	Checks whether stack is empty
isFull()	Checks whether stack is full


Example

Push: 10
Push: 20
Push: 30

Stack:
30
20
10

Pop: 30
Top: 20

LIFO Principle

The last element inserted into the stack is the first element removed.

TOP
         ↓
       [30]  ← Pop
       [20]
       [10]
